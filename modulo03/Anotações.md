O LAÇO FOR É INDICADO USAR QUANDO SE SABE QUANTAS VEZES SE QUER REPETIR ALGO QUE ESTÁ PERCORRENDO UMA SEQUENCIA DE ELEMENTO

USE O FOR QUANDO:
- SE SABE QUANTAS VEZES PRECISA REPETIR UMA SEQUENCIA
- PERCORRER UM ARRAY
-CONTROLAR UM CONTADOR



USE O WHILE QUANDO:
- SE NÃO SABE QUANTAS VEZES PRECISA REPETIR UMA SEQUENCIA
- REPETIÇÃO DEPENDE DE UMA CONDIÇÃO
-CONTROLAR UM CONTADOR
-O ENCERRAMENTO DEPENDE DE UM ACONTECIMENTO EXTERNO
