O PHP é considerado uma linguagem interpretada, sim.
Isso porque, de forma geral, o código PHP é executado linha a linha por um interpretador (o motor do PHP, tipo o Zend Engine) — não precisa compilar o código inteiro antes de rodar, como acontece em linguagens compiladas tipo C++.

Resumindo:

Você escreve o código (.php).

O interpretador do PHP lê e executa em tempo real.

Ele interpreta o script e gera o resultado (HTML, JSON, etc.) que é enviado para o navegador.
